# Seed data: FICTIONAL

Everything in this folder is **fictional placeholder data** for development and tests.
The candidates, parties, videos, URLs and quotes do not exist. Do not present it as real.

Real data goes in `data/real/` (set `ONRECORD_DATA_DIR=data/real`), added by hand from
real public videos and verified by a person (see docs/SOURCES.md and docs/DATA_FORMAT.md).
